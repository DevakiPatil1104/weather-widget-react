# Weather Widget (React)

A responsive weather application built using **React.js** that fetches and displays real-time weather data using an external Weather API.

## Features
- Search weather by city
- Real-time weather data
- Displays temperature, humidity, and weather conditions
- Clean and responsive UI
- API-based data fetching

## Tech Stack
- React.js
- JavaScript
- HTML5
- CSS3
- Weather API
- Vite
